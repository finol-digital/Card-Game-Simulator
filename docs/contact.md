# Contact Card Game Simulator

Card Game Simulator is developed and published by Finol Digital LLC. We welcome questions about using the app, creating or sharing a compatible card game, reporting a problem, and privacy-related requests. When asking for support, include the platform you are using, the app version when available, and a concise description of what happened. That information helps us reproduce and investigate an issue without asking you to share unnecessary personal information.

- **Support email:** [david@finoldigital.com](mailto:david@finoldigital.com)

For feature ideas and public project discussion, visit the [Card Game Simulator GitHub repository](https://github.com/finol-digital/Card-Game-Simulator) or the [community subreddit](https://www.reddit.com/r/CardGameSimulator/). Please do not include passwords, payment information, or other sensitive information in support messages. For information about data handling and privacy requests, review the [privacy policy](/privacy/).

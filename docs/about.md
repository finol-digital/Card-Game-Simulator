# About Card Game Simulator

**No account or registration is required to play CGS, including online multiplayer.** Start with the [How to play guide](/how-to-play/) for a practice table, mouse and touch controls, and instructions for hosting or joining friends.

Card Game Simulator (CGS) is a virtual tabletop for people who want to create, share, and play card games without being locked into one ruleset. It provides a flexible play area for custom cards, decks, boards, and game materials, so hobbyists, playtesters, designers, and established communities can explore their own games. Players can use CGS on the web and on supported desktop and mobile platforms, then play locally or online with friends.

CGS is developed and published by Finol Digital LLC. The project is community-oriented and its source code is available on [GitHub](https://github.com/finol-digital/Card-Game-Simulator). Creators can publish compatible games through [CGS Games](https://cgs.games/), where players can discover and try community-made content. To learn how to create a game, start with the [CGS game-development guide](https://github.com/finol-digital/Card-Game-Simulator/wiki/Crash-Course-into-Game-Development-with-CGS).

For product support, partnership questions, or privacy requests, see the [contact page](/contact/). For information about how the service handles personal information, read the [privacy policy](/privacy/).
